# Banana Canvas 核心交互优化设计

## 目标

在保留 RunningHub 用户操作习惯的前提下，让单画布包含 100-300 个节点时仍可顺畅完成平移、缩放、拖拽、框选、连线和撤销。优化以用户体验为最高优先级，不增加与核心画布无关的功能。

## 方案选择

采用渐进式交互内核重构：继续使用当前原生 HTML、CSS 和 JavaScript，不引入 React Flow 等大型画布框架；将高频交互从全量 `render()` 改为按帧局部更新。这样可以保留已有工作流、节点面板、生成逻辑和本地存储格式，同时显著降低回归范围。

未采用的方案：

- 只调整动画和样式：改动小，但无法解决拖拽时整张画布反复重建的问题。
- 整体迁移到 React Flow：长期扩展性较强，但需要重写节点、连线、视口和持久化，当前阶段风险和工作量过高。

## 交互模型

画布只允许一个主交互状态：`idle`、`selecting`、`dragging`、`panning` 或 `connecting`。状态切换统一处理指针捕获、光标、取消、提交历史和保存，避免拖拽、框选、平移互相抢占。

- 左键点击节点：选中节点。
- 左键拖动节点：移动当前节点；已多选时移动整个选择集。
- 左键拖动空白处：框选节点。
- `Shift + 点击`：追加或移除选择。
- 鼠标中键：在画布、节点和悬浮面板上都可平移画布，不拖动节点。
- 普通滚轮：垂直平移；`Shift + 滚轮`：水平平移；`Ctrl + 滚轮`：以鼠标为中心缩放。
- `Escape`：取消正在进行的框选、拖线或菜单。
- 每次拖拽、框选、连线只形成一个撤销事务，不记录中间帧。

## 渲染架构

拆分结构渲染和交互帧渲染。

- 结构渲染：仅在新增、删除、切换画布、生成结果或节点内容变化时重建必要 DOM。
- 交互帧渲染：使用 `requestAnimationFrame` 合并指针事件，只更新节点位置、选择框、视口变换、连线路径和悬浮面板坐标。
- 节点 DOM 以 `card.id` 缓存，拖拽时直接更新 `transform`，不替换图片、视频或输入控件。
- 平移和缩放只更新画布容器变换；小地图和本地保存以较低频率刷新。
- 删除、切换画布等结构变化后执行一次完整几何同步，确保端口和连线中心准确。

## 节点拖拽与吸附

- 指针移动超过 4 像素后才进入拖拽，避免点击时节点轻微跳动。
- 默认使用 16 像素网格吸附，并在接近其他节点的左、右、上、下和中心线时显示对齐参考线。
- 对齐阈值为屏幕空间 6 像素，缩放后手感保持一致。
- 按住 `Alt` 临时关闭网格和对齐吸附。
- 多选拖拽以选择集边界吸附，节点之间的相对位置保持不变。
- 拖到浏览器边缘继续自动平移，但使用平滑加速和最高速度限制，松开后立即停止。

## 连线交互

- 端口视觉尺寸保持克制，实际命中区域扩大到至少 24 像素。
- 拖线时只更新临时曲线，不重建节点。
- 可连接目标高亮为香蕉绿；无效目标显示红色反馈；已存在的重复连接不创建。
- 松开到空白处继续显示“引用该节点生成”菜单，并将菜单放在指针附近且限制在视口内。
- 连线可点击选中并通过 `Delete` 删除；选中反馈不改变节点布局。

## 选择、分组与快捷操作

- 框选实时显示命中的节点，松开后提交选择。
- `Shift` 支持增量框选和增量点击。
- 新增 `Ctrl + D` 原位偏移复制所选节点；复制结果自动选中。
- 分组移动沿用多选拖拽，不引入复杂嵌套分组。
- 自动布局、删除、粘贴和复制均产生清晰且可撤销的一次操作。

## 悬浮面板和菜单

- 节点操作面板保持悬浮在节点下方，间距约 12-16 像素，不遮挡节点。
- 面板跟随节点和视口变换，但允许被浏览器边界裁切，不触发画布自动平移。
- 参数上拉菜单、参考图预览和连线菜单使用统一的视口定位器，避免鼠标移动过程中出现不可跨越的间隙。
- 菜单开启时仍允许中键平移；左键操作只作用于菜单控件本身。

## 小地图

- 保持默认开启和当前可读尺寸。
- 显示当前视口矩形、节点类型色块和选择状态。
- 点击小地图跳转到对应位置；拖动视口矩形连续平移主画布。
- 拖动小地图期间不触发节点选择或画布框选。

## 历史与保存

- 拖拽开始时保存事务前快照，结束时仅在状态实际变化后加入撤销栈。
- 连续滚轮平移和缩放合并为短时间窗口内的一次历史操作。
- `localStorage` 保存采用 300 毫秒防抖；切换画布、关闭页面和生成任务状态变化时立即保存。
- 保存失败时保留内存状态并显示简短错误，不清空用户当前工作。

## 性能验收

- 100 个普通节点下，拖拽和平移目标帧时间不高于 16 毫秒。
- 300 个普通节点下，交互帧时间目标不高于 32 毫秒，操作期间不丢失选择或连线状态。
- 拖动包含图片或视频的节点时，媒体 DOM 不被替换，不出现图片被浏览器拖走或视频重新加载。
- 高频指针移动不会在每次事件中写入 `localStorage` 或重建所有节点。

## 验证

- 静态回归检查覆盖交互状态、局部渲染、吸附、连线选择、小地图拖动、历史事务和防抖保存。
- 浏览器自动化覆盖左键框选、中键平移、节点拖拽、Shift 多选、Alt 取消吸附、拖线创建和删除连线。
- 构造 100 与 300 节点测试画布，记录拖拽和平移的帧耗时，并检查媒体元素在交互前后保持同一 DOM 实例。
- 对现有图片生成、视频生成、电商工作台、多画布切换、导入导出进行回归验证。

## 非目标

- 本阶段不迁移前端框架。
- 不加入 3D、剪辑、导演台、音频等未实现模块。
- 不改变 Agnes API 请求格式和现有画布数据结构。
- 不追求 500 个以上节点的完整虚拟化。
